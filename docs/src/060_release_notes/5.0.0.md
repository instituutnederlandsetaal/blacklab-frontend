# 5.0.0

This is mostly a formality release to align with **BlackLab 5**.

## Breaking Changes
- Migrate javax -> jakarta (de1d4fbf)
  This requires updating Tomcat to a version that supports Jakarta, typically Tomcat 10 or later.

## Fixes
- Fix annotation and metadata autocomplete not working when using **Blacklab 5** (74e941aa)
- Fix several query restoration edge-cases (f21f98f4)

## Features
- Allow adding custom pages apart from `about` and `help`. 
  Add additional `.inc` files, these are available in the browser under `<corpus>/pages/<page>` (minus the `.inc` extension)

## Documentation
- The docs site now contains versioned documentation for different releases, making it easier to reference specific versions of the BlackLab frontend.

## Miscellaneous
- Update build scripts & documentation for 5.0.0 release (f4979bdd)
- Automate stable releases, Docker images and versioned documentation (4fc626a6)
